# Supplied Drawings

The project owner authorized public distribution of these ten supplied drawing files on October 12, 2026. The directory was renamed from `disegni` to `drawings`; file contents and existing identifiers were preserved.

These drawings are experiment inputs, not project-authored software. The repository's MIT license applies to project code and documentation; it does not automatically license the drawings or transfer their ownership. No additional reuse license for the drawings is asserted here.

Selected CAD reconstructions are available on the documentation site. They are drafts, not dimensionally certified engineering documents. The separate `disegni-originali` directory is not published.
